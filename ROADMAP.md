# Respawn development roadmap

## Milestone 1: Mobile foundation
- [x] Expo React Native app scaffold
- [x] Dark Respawn visual identity
- [x] Home, Discover, Games, Messages and Profile navigation
- [x] Search and local demo interactions
- [x] Sample games, players and communities
- [ ] Install and run on a physical Android device
- [ ] Add app icon and launch artwork

## Milestone 2: Real accounts and community backend
- [ ] Choose and configure a free-tier backend (Supabase is the current candidate)
- [ ] Secure sign-up, sign-in, sign-out and password reset
- [ ] Player profiles and avatar uploads
- [ ] Friend requests and blocking/reporting
- [ ] Communities, membership, roles and permissions
- [ ] Guilds, recruitment and events
- [ ] Direct and group messaging with realtime updates
- [ ] Push notifications

## Milestone 3: Gaming identity
- [ ] Steam sign-in and public profile/game data where permitted
- [ ] Xbox integration using supported Microsoft identity and APIs
- [ ] Evaluate PlayStation, Epic, Nintendo, EA, Ubisoft, Riot and Battle.net official integration options
- [ ] Store linked account identifiers securely; never collect platform passwords
- [ ] Game library, activity and achievements where APIs permit

## Milestone 4: Player discovery
- [ ] Looking-for-group posts
- [ ] Matchmaking preferences (games, platform, region, play style)
- [ ] Game hubs and discussion feeds
- [ ] Clips, screenshots, reviews and guides
- [ ] Tournaments and community events

## Principles
- No paid AI APIs.
- No subscription requirement.
- Core features should be usable without paying.
- Do not promise integrations that a platform does not officially support.
- Keep demo content clearly labelled until connected to live services.
